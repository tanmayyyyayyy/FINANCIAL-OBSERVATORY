# Interface Preview Captures

This directory contains visual captures of the Financial Observatory interface across viewports and interaction states:

- `01-landing-hero.png` — Spatial terrain view with glowing atmospheric telemetry.
- `02-observatory-dashboard.png` — Real-time capital velocity, inflow/outflow metrics, and allocation breakdowns.
- `03-budget-control.png` — Category envelope calibration, burn thresholds, and headroom analytics.
- `04-ledger-trail.png` — Searchable, filterable transaction ledger with settlement rail tracking.
- `05-prediction-engine.png` — Extrapolated month-end run rates with interactive discretionary spending delta simulator.
- `06-settlement-receipt.png` — Committed movement receipt with real-time state verification telemetry.
